# Power BI Northwind Dashboards

This project contains interactive dashboards built using the Northwind dataset.

## Overview Dashboard
- Total Sales
- Total Sales vs. Last Year Sales
- Total Orders
- MoM Sales Growth

## Customers Dashboard
- Customers by Country (Map)
- Top Countries by Customers
- Active Customers (>10 orders)
- Orders Distribution
- Active Customers vs. Non-Active Customers

## Categories Dashboard
- Total Sales and Units Sold by Category
- Average Price by Category
- Category Orders Trend
- Total Sales by Products

## Tools Used
- Power BI
- DAX
- Data Modeling
